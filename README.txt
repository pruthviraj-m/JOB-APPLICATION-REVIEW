TALENTMATCH RECRUITMENT ANALYTICS DASHBOARD

This fixed demo is populated immediately using the six sample records displayed
in the project PPT. It does NOT claim that those six records are the full
1,000,000-row Kaggle dataset.

Technology aligned with the PPT:
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js + Express
- Database target: MongoDB

Run:
1. Install Node.js.
2. Open this folder in a terminal.
3. Run: npm install
4. Run: npm start
5. Open: http://localhost:3000

The current standalone dashboard does not require MongoDB to display the demo.
MongoDB can be connected later for live project data.
